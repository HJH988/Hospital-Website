# CRUD App Scaffold

This workspace contains a scaffold for a CRUD application with a React frontend and a Go + Gin backend.

## Structure

- `frontend/`
  - `src/components/`
  - `src/pages/`
  - `src/services/`
  - `src/App.jsx`
  - `package.json`
- `backend/`
  - `main.go`
  - `routes/`
  - `controllers/`
  - `models/`
  - `database/`
  - `go.mod`

## Notes

- The frontend and backend are scaffolded as placeholders.
- Add your React components, pages, and API services in `frontend/src/`.
- Add your Go controllers, models, routes, and database logic in `backend/`.
