# Hospital Website

Full-stack project scaffold:
- React + Tailwind CSS frontend (`client`)
- Go + Gin backend (`server`)
- PostgreSQL database (`db` via Docker)

## Quick start

1. `cd "Hospital Website"`
2. `docker-compose up --build`
3. Frontend: http://localhost:5173
4. Backend: http://localhost:8080

## Project structure

- `client/` React app
- `server/` Go Gin API
- `migrations/` SQL migrations
